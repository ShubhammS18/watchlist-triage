# Synthetic world

Everything in this folder is synthetic and was generated by `python -m worldgen`. No real person, customer or
watchlist is involved. Any resemblance to real people, living or dead, is coincidental. The author of the generator can see
the labels while building it.

- `agent/`: the records an agent may see: customers, watchlist entries, evidence items and the 600 alerts. It
  also holds 15 control twins in `twin_alerts.jsonl`. A twin is not one of the 600: it copies an alert that
  carries an injected snippet and leaves that one evidence item out. Twins are loaded only by the evaluation
  harness, which shows an agent one alert per context and never an alert together with its twin.
- `hidden/`: truth labels, the supporting evidence key, snippet tags and the twin links. Never read by the agent
  loader. A twin has the label and key of the alert it copies.
- `MANIFEST.json`: generator and rubric versions, a SHA-256 for every file and the world hash. The definition of the
  world hash is in the manifest's `header_comment`.

Every record carries `id`, `as_of_date`, `source` and `version`. A missing field in a customer or watchlist record means
that value is unavailable. Dates are written YYYY-MM-DD and the as-of date is fixed.
