## Findings

1. **SHOULD — A pre-change aborted run can make unrelated sets in its output folder ineligible.** `harness/schema.py:139-143`, `harness/score.py:374-394`, `docs/w2-06-boundary-checks.md:25-28`. The old writer used `aborted.message` and the old index used the raw-text cause; the new strict schema requires `message_sha256`. An in-memory check of the old abort object returns `aborted lacks message_sha256`. Under `DEC-T06-MANIFEST-9`'s global fail-closed rule, that old run is unassigned and no set in the folder is eligible, even if other runs are intact. The doc discloses this, so it is an intentional compatibility break, but earlier tasks kept old written shapes valid and aborted runs were already excluded from baseline counts. **Fix:** accept a separately specified, fully validated legacy abort shape and its matching legacy index cause, or version and migrate old output folders before applying the new schema. Keep all newly written abort records hashed. If the owner deliberately wants this incompatibility, record that policy and its effect on unrelated sets explicitly.

2. **SHOULD — One requested T06 by-hand proof no longer proves its named guard.** `tests/t06_harness/mutations.py:166-169`, `harness/run.py:420-426`, `tests/t06_harness/test_mutation.py:29-36`. Mutation 36 inserts `environment` into `from_inputs`. The later preflight indexes the shared schema by each `from_inputs` key and raises `KeyError: 'environment'` before a run writes anything. The named `test_no_environment_variable_reaches_any_output` therefore errors instead of failing its assertion, which the mutation contract requires. The full `T06_MUTATION=1` run reported this row as `passed, passed`; an isolated repeat reproduced it. This is a pre-existing interaction with the W2-03 preflight, not a W2-06 production regression. **Fix:** retarget the mutation to the final manifest assembly, after preflight, so the named output guard sees the planted environment variable and fails with the expected assertion; retain the untouched-copy and exact-reason requirements.
