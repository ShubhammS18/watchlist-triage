# Name parts

The given-name, family-name and title lists in this folder are invented. The name parts were
made by a script that is not kept in this repository and were then filtered by hand. They are
not copied from any list of real names.

Any resemblance to real people, living or dead, is coincidental. No claim is made that a part
is free of overlap with a real name or word in some language.

The nationality values used elsewhere in the world are real country adjectives and are not
part of these lists.
